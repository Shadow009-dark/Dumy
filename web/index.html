Salam, mən DUMY-yəm

Maldarlıq, aqronomiya və gündəlik hesablamalar üzrə yerli sənədlərə əsaslanan köməkçinizəm. Sualınızı yazın və ya aşağıdakılardan birini seçin.

DUMY lokal kiçik modeldir; vacib qərarlar üçün mənbəni yoxlayın.

Yerli model · məlumatlar kompüterinizdə qalır

Yaddaş

Yalnız özünüz haqqında açıq şəkildə dediyiniz qısa faktlar saxlanılır (məsələn: “30 qoyunum var”). Şifrə, telefon, sənəd nömrəsi və sağlamlıq məlumatı saxlanılmır.

Parametrlər

Server API açarı tələb edirsə, buraya yazın. Açar yalnız bu brauzerdə saxlanılır.

Səs tanıma brauzerin xidməti ilə işləyir və internet tələb edir. Audio DUMY serverinə göndərilmir və heç yerdə saxlanmır.
